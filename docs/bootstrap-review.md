# v0.0 작업 및 검증 기록

2026-11-03. 빈 디렉터리에 계약·명세·스킬·테스트·CI를 구성했다. 영향 범위는 신규 오프라인 하네스이며 기존 코드 변경은 없다. RCAEval 문서의 익명 task 폴더와 별도 answers 파일 구조를 검토했다.

Python 3.12.13에서 `UV_OFFLINE=1 make check`: Ruff lint 및 format, 스킬 동기화, pytest 22건 통과. 계약 테스트는 유효 입력과 Mock 인터페이스, 미허용 후보·없는 evidence·중복·case 불일치·불완전한 JSONL을 확인한다. 보안 테스트는 중첩 정답 필드·알려진 비밀 표식·답안 파일·심볼릭 링크를 검사한다. 스킬 작성기 형식 검사 3건도 통과했다. 이러한 테스트는 한정된 예시를 검증할 뿐 실환경 격리나 RCA 품질을 입증하지 않는다.

리뷰에서 PyPI RCAEval 1.7.0에 upstream 문서의 `rcaeval-agent` CLI가 없음을 확인했다. 선택적 패키지 설치만으로 실제 평가를 실행할 수 없고, 평가 전 CLI가 포함된 upstream 버전과 별도 환경을 확인해야 한다. GitHub Actions 원격 실행, Claude/Codex의 새 세션에서 실제 지침·스킬 인식, 실제 데이터 및 OS 격리는 검증하지 않았다. RCA 추론, 모델, 그래프, UI, RCAEval 변환기 및 채점은 미구현이다.

v0.1 진행 전 제품 범위, 후보와 데이터 기준, 평가 및 정확도 목표, 외부 호출과 비용·요청 한도, 보존 정책 및 격리 방식을 결정하고 명세와 설정에 반영한다.
