# 평가 데이터 격리 정책

[RCAEval blind export](https://github.com/phamquiluan/RCAEval/blob/main/docs/AGENTS.md)는 익명 `dataset/cases/...`와 별도 형제 `dataset.answers.jsonl`을 만든다. 원본 디렉터리 이름에도 정답이 들어갈 수 있고 export는 기본적으로 원본 telemetry를 하드링크할 수 있다.

실제 평가 전 별도의 권한 경계에서 에이전트에 blind 작업 디렉터리만 읽기 전용으로 제공한다. 원본 데이터, 정답 파일, 부모 디렉터리 및 평가자 결과는 마운트하지 않고 접근 권한을 주지 않는다. 네트워크와 환경 변수, 도구 접근을 최소화하고 작업 디렉터리에 심볼릭 링크나 정답 파일이 없음을 사전 검사한다. 하드링크는 원본과 내용을 공유하므로 쓰기 권한을 주지 않는다. `--copy`로 내보내는 것도 고려한다. 실제 접근 제한은 운영 환경에서 별도로 검증해야 한다.

이 저장소의 검사는 숨겨진 정답 필드와 제공된 비밀 표식, 경로 내 답안 파일·심볼릭 링크를 탐지하는 방어 보조 수단이다. 임의의 인코딩, 의미적 누출, 공개 데이터 역매칭, 권한 설정 오류 및 하드링크 자체를 증명하거나 막지 못한다. 기본 테스트는 예시 데이터만 사용한다. Phase 1의 실제 데이터와 읽기 전용 컨테이너 격리 검증 및 한계는 `reports/phase1-compatibility-verification.md`를 참조한다. 공식 평가자 호환 실행에서는 답안과 ID 매핑을 blind 마운트 밖의 평가자 전용 영역에 둔다.
