# Phase 4B-3A 검증 기록

상태: **오프라인 구현 및 로컬 검증 완료**. 공식 SDK와 Mock HTTP만 사용한다. 실제 네트워크 전송과 인증은 연결하지 않았다.

- 불변 `PreparedRequest`를 입력 토큰 계산과 모델 호출에 사용한다. 모델·지침·입력·스키마·도구가 일치하며, 계산 후 입력·최대 출력 토큰 및 비용을 예약한다. 계산 실패, 잘못된 사용량, 시간 초과 및 한도 초과는 실패로 처리한다. SDK 자동 재시도는 끄고 불명확한 사용량에서는 Broker를 차단한다.
- 요청은 코드에서 `api.openai.com/v1/responses`와 `/v1/responses/input_tokens`에 한정한다. Mock transport만 사용하며 코드 수준 제한은 OS 네트워크 격리가 아니다. 실제 키나 실제 API 호출은 사용하지 않았다.
- Mock 시험은 정상 요청, 스키마 구조 및 잘못된 출력, 429·5xx·거부·불완전 응답, 시간 초과, 사용량 누락·잘못된 타입, 입력 토큰·비용 한도, 요청 불변성과 재시도를 검증한다. SDK의 토큰 사용량 타입 강제 변환을 피하기 위해 원본 JSON을 검증한다. SDK 내부 스키마 변환 헬퍼에 의존하므로 SDK 갱신 시 호환성 검증이 필요하다.
- 실제 모델의 스키마 수용 및 실제 토큰 계산 정확성은 **미검증**이다. 테스트 가격과 Budget은 운영 정책이 아니다. 로컬 Broker의 타임아웃은 작업 스레드의 종료나 외부 요청 취소를 보장하지 않는다.
- Phase 4B-3B는 Agent 자격 증명 접근 차단, Broker의 원본·정답·매핑·비공개 표본 키 접근 차단, 승인된 API에 대한 OS 네트워크 제한 및 그 검증이 선행되어야 한다. 실제 유료 호출은 별도 승인 및 운영 예산·가격·보존 정책 결정 이후에만 가능하다.
